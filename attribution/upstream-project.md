# Upstream Project Attribution

The Employee Management System application originated from this open-source project. 

My contribution was the security-focused academic work performed on a local copy, including:
- threat modelling
- vulnerability/security assessment
- access-control hardening
- secure configuration changes
- remediation
- SAST
- dependency analysis
- DAST
- manual security validation
- regression testing
- security automation

I did not originally develop the Employee Management System, and I do not claim authorship of the original Django application logic or codebase.
